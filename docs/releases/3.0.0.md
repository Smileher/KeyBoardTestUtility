- The rebuilt Vue 3 and Tauri 2 edition uses version 3.0.0, following the original WinUI 2.0.0.0 release published to Microsoft Store in 2022.
- Windows Store packages use version 3.0.0.0 and preserve the original application identity.

- Redesigned the tester around seven top-level categories: keys, chatter, rollover, dropouts, event delay, typing, and mouse. Each category has a short explanation and independent results; detailed event records are collapsed by default.
- Added Simplified Chinese, Traditional Chinese, English, German, French, Japanese, Korean, and Spanish, with localized instructions, settings, results, and typing passages.
- Added US ANSI, UK ISO, German QWERTZ, French AZERTY, and Japanese JIS physical layouts for Windows and Mac. Win/Mac selection uses segmented buttons. Mac geometry follows the Apple full-size keyboard, with symbol-and-English modifiers, F13–F19, a distinct numpad, and JIS-specific positions. Fn and Touch ID are excluded from progress.
- Added suspected short-gap chatter/dropout reports with configurable thresholds, simultaneous-combination testing with custom key selection, and separate browser/native event-delay statistics. Delay results are application event timings, not total hardware latency.
- Added typing speed and accuracy with Unicode normalization, normal editing, and IME-aware input. Native capture pauses during typing; typed content is not logged.
- Moved five-button mouse feedback into its own test area. Toolbar clicks do not enter the records; each category keeps at most 1,000 in-memory events.
- Retained the original animated sun/moon switch and circular theme reveal. Native Windows/macOS title bars follow the theme preference. The centered desktop window now supports resizing and maximizing and fits the monitor work area.

Mac hardware, system-reserved keys, and region-specific physical keyboards still require manual verification. Short-gap reports are suspected events, not a definitive hardware diagnosis.
